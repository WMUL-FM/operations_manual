17. RD Library (Managing)

This part covers how to manage carts within RD Library. See 14.F. RD Library (Searching) on Page 27 in Volume III for information on using RD Library to search and an explanation of the numerous metadata fields. See also 18. Ingesting New Audio with Adobe Audition on Page 101 in Volume III.

17.A. Editing a Cart

This chapter covers how to edit a cart’s metadata from inside RD Library. It first covers editing the cart level metadata, then the cut level metadata. It then explains the different ways that the Start and End dates are used, depending on the origin of the cart.

17.A.1. Editing Cart Metadata

Double-click on a cart in RD Library to open the "Edit Cart" dialog.

Most of the meta-data fields are either self-explanatory, or were explained in 14.F.1. Metadata Fields on Page 29 in Volume III. The Number, Type, and Average Length fields are read-only.

  1. Group Box: Use this box to change the group assignment for the cart.

  2. Enforce Length: Do not use this. When this is checked, the cart will be time-scaled to match the value in "Forced Length" (4). If you need a cut to be a specific length, it is better to use the time-scaling functions in an audio editor, such as Adobe Audition.

  3. Forced Length: When "Enforce Length" is checked, this is the length to which the cart will be time-scaled. Once again, if you need a cut to be a specific length, it is better to use the time-scaling functions in an audio editor, such as Adobe Audition.

  4. Scheduler Codes: Click this button to bring up the list of scheduler codes. You can add or remove codes using this dialog. 14.J. List of Scheduler Codes on Page 39 in Volume III

  5. Schedule Cuts: Use this to determine whether to schedule the individual cuts within the cart "By Weight" or "By Specified Order". 17.B.1 Cut Rotation on Page 82 in Volume III

  6. Add: Add a cut to the cart. The new cut will initially be blank. 17.E.2. Importing a Cut from a File on Page 94 in Volume III and 17.E.4. Copying a Cut from One Cart to Another on Page 96 in Volume III

  7. Delete: Delete the highlighted cut from the cart. 17.E.6. Removing Audio on Page 97 of Volume III

    Deleting audio is permanent! There is no undo.

    "Oops!" is not an acceptable excuse.

  8. Copy: Copy the selected cut to the clipboard.

  9. Paste: Paste the cut that is on the clipboard over the selected cut. If you wish to add a new cut from what is on the clipboard: click "Add", select that blank cut, and then click "Paste"; otherwise, you will overwrite an existing cut.

  10. Cut List: The list of cuts within this cart.

  11. Edit Notes: Brings up a text-box to edit the "Notes" field. That field is not searchable, but may be viewed on the RD Library main window via tooltip when the "Show Note Bubbles" box is checked.

  12. Cut Info | Record: Click this to open the Cut Info | Record dialog box. Use this to edit the cut-level meta-data or record new audio. 17.A.2. Editing the Cut Info on Page 80 in Volume III and 17.E.5. Recording a Cut on Page 96 in Volume III

  13. Edit Markers: Click this to open the "Edit Audio" dialog box. Use this to set the markers in the audio. 17.D.1. Editing Cart Markers on Page 91 in Volume III

  14. Import | Export: Click this to bring up the "Import/Export Audio File" dialog box. 17.E.2. Importing a Cut from a File on Page 94 in Volume III and 17.E.3. Exporting a Cut to a File on Page 95 in Volume III

  15. Rip CD: Allows a CD to be ripped directly into Rivendell. Since importing audio in this manner does not permit the audio to be edited for language before ingesting, WMUL‑FM does not use this function. See 18. Ingesting New Audio with Adobe Audition on Page 101 in Volume III for instructions on how to ingest and edit CDs with Adobe Audition.

17.A.2. Editing the Cut Info

From within the "Edit Cart" dialog, select a cut and click the "Cut Info | Record" button to open the "Cut Info / Record" dialog box. You may also double-click on the cut.

This dialog may be roughly divided into three sections. The top section (1) describes the cut, the middle section (2) controls the daypart settings, and the bottom section (3) contains the recording and playback controls. Click the play button to play the cut through the preview channel. 17.E.5. Recording a Cut on Page 96 in Volume III

17.A.3. Start and End Dates in RD Library

These two fields have different meanings depending on how the cart was ingested. If the cart was imported from WOAFR, or using Adobe Audition 3.0, the start date will be the date the song was originally ingested and the end date will be centuries in the future.

If the cart was created within Rivendell, or ingested using Adobe Audition 2024+, the start date will be blank, unless a start date was actually set. The end date will be "TFN" ('Till Further Notice), unless an end date was actually set.

If a cart has multiple cuts, it will display the widest range of dates for which any cut will play. If any cut has no start and end date, then the cart will display a blank start date and a "TFN" end date. Example: Cut 001 has a start date of 06/01/2020 and an end date of 06/07/2020. Cut 002 has a start date of 06/08/2020 and an end date of 06/14/2020. Therefore, the cart will display 06/01/2020 - 06/14/2020.
