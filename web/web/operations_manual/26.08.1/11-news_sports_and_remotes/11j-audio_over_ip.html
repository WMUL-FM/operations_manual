11.J. Audio over IP (Linphone)

Another option for bringing in a remote broadcast crew is using Linphone on the Audio over IP computer. Linphone is a Voice over IP client similar to (the now defunct) Skype.

Linphone creates a high-quality audio connection over Internet connections. Linphone is available on the Audio over IP computer in Studio A. It is the right-hand computer on the left-hand counter top. For remote users, it is installed on both laptops and both iPads.

11.J.1. Receiving a Call on Linphone

For technical reasons, it is usually easier for the remote crew to place the call and for the studio to answer it.

  1. Double-click on the "Linphone" icon on the desktop. The "Linphone" window will appear.

  2. Let the remote crew know (using a cell phone, text message, or Teams message) that you are ready for them to connect.

  3. A few seconds after the remote crew has placed the call, a black rounded window will pop up in the lower right-hand corner of the screen. The name of the caller should correspond to the device the remote crew is using. E.G. "Laptop #5" or "Sports iPad". Click the "Accept" button to take the call.

  4. It may take a few seconds for the connection to fully establish and for audio to begin flowing between the studio and the remote site.

11.J.2. Placing a Call on Linphone

  1. Double-click on the Linphone icon on the desktop. The Linphone window will appear.

  2. Find out the address of the remote site. If the remote site is using one of WMUL-FM’s laptops or iPads, those accounts are in the contacts list. If you are at the remote site and are dialing back to the studio, the Audio Over IP computer will be the only contact in the contacts list.

  3. Select the contact in the contacts list.

  4. Wait for the remote crew to indicate (via cell phone, text message, or Teams message) that they are ready for you to connect.

  5. Click the "Call" button to begin connecting.

  6. The remote crew will answer on their end.

  7. It may take a few seconds for the connection to fully establish and for audio to begin flowing between the studio and the remote site.

11.J.3. Troubleshooting Linphone (From the Studio)

Remember that there can always be multiple problems and you need to tackle the problems one by one. Do not panic just because the problem was not fixed on the first attempt. Stay calm and work the problem.

11.J.3.a. They Can’t Connect! (Checking the Network at the Studio End)

If the remote crew is having trouble making a connection, the first thing to check is whether the Audio Over IP computer and Linphone can talk to the internet. (The Audio Over IP computer in Studio A runs Linux Mint, but the Laptops run Windows 11; therefore, some of the network icons will be different on each end.)

  1. In the lower right-hand corner of the screen, check the network icon. If everything is connected, it should be an icon of a network jack.

    If there is no internet connection, it will be an icon of two arrows with an X.

    1. If there is no internet connection, try rebooting.

    2. If the problem persists, call the Operations Manager.

  2. Inside Linphone, check the user icon in the upper right-hand corner of the screen. The colored dot in the lower right-hand corner is the status icon.

    1. A green, yellow, or red icon of a dot indicates that Linphone is connected and accepting calls.

    2. A red icon of an exclaimation point inside a circle indicates that Linphone has been unable to connect to its servers.

      1. Click the user icon and then the "Error" button. Linphone will re-try to connect.

      2. Try closing and restarting Linphone. To close Linphone, you must click the kebab menu in the upper right-hand corner, to the right of the user icon, then select "Quit the App". The "X" button in the upper right-hand corner only minimizes Linphone to the system tray.

      3. Try rebooting.

      4. If the problem persists, Linphone will not work today. You will need to switch to using the Access, Opal, or Gentner.

    3. A red icon of a dot with a white horizontal line across it indicates that Linphone is in "Do Not Disturb" mode. In this mode, Linphone will not ring on incoming calls.

      1. Click the User menu, then change the "Do Not Disturb" setting to "Available".

  3. If the remote site is still unable to connect, the problem is likely on the remote end.

11.J.3.b. I can hear the remote crew, but they can’t hear me! (Audio Problems — Studio End)

Unfortunately, newer versions of Linphone do not provide meters to check the audio going in and out of the program.

  1. Check the routing and the console:

    1. Check that the source for "AoIP d" is set to "A Phn 1s" (or whichever studio and phone module you are using).

    2. Check the SuperPhone module in the audio console. Make certain that it is turned off and the appropriate caller module (Phone 1 or Phone 2) is in cue.

    3. Make certain that the "TB" knob is turned up. It should usually be at about "6", but try turning it up.

    4. Make certain that "MXM Source" is set to "AUD".

    5. Make certain that the Rivendell is in "PGM" and "AUD".

  2. In the Linphone call window, click the kebab menu button down at the bottom, then "Settings". The "Settings" window will appear on the right-hand side of the screen.

    1. "Microphone" should be "PulseAudio: DSP56361 Digital …​".

  3. Try reconnecting.

  4. Try rebooting.

11.J.3.c. The remote crew can hear me, but I can’t hear them! (Audio Problems — Studio End)

Unfortunately, newer versions of Linphone do not provide meters to check the audio going in and out of the program.

  1. Check the routing and the console:

    1. Check that the source for "A Phn 1d" (or whichever studio and phone module you are using) is set to "AoIP s".

    2. Check the SuperPhone module in the audio console. Make certain that it is turned off and the appropriate caller module (Phone 1 or Phone 2) is in cue.

    3. Make certain that the "Cue" knob is turned up. It should usually be at about "5", but try turning it up.

    4. Make certain that the CR Microphones are all turned off.

  2. In the Linphone call window, click the kebab menu button down at the bottom, then "Settings". The "Settings" window will appear on the right-hand side of the screen.

    1. "Speaker" should be "PulseAudio: DSP56361 Digital …​".

  3. Try reconnecting.

  4. Try rebooting.

11.J.4. Troubleshooting Linphone (From the Remote End)

Remember that there can always be multiple problems and you need to tackle the problems one by one. Do not panic just because the problem was not fixed on the first attempt. Stay calm and work the problem.

11.J.4.a. We Can’t Connect! (Checking the Network at the Remote End)

Checking the network connection will depend on the device type (Windows Laptop, iPad, or other) and the network connection type (wired or WiFi). (The Audio Over IP computer in Studio A runs Linux Mint, but the Laptops run Windows 11; therefore, some of the network icons will be different on each end.) This manual will only cover network troubleshooting for a Windows 11 Laptop or an iPad, because those are the two types of devices owned by WMUL‑FM.

Windows Laptop — WiFi

  1. In the lower right-hand corner, click on the WiFi icon.

  2. Look at the WiFi settings icon. If WiFi is connected, it should be blue and list the name of the WiFi network below it.

  3. Click the arrow to open the list of WiFi networks.

    1. Make certain that you are connected to the expected network.

    2. Make certain that the network that you are connected to says "Connected, secured" and does not say anything like "no internet".

    3. Try disconnecting and reconnecting. MU WiFi sometimes makes internal changes that require everyone to reconnect.

  4. Try rebooting.

  5. Find a network technician.

Windows Laptop — Wired Ethernet

  1. In the lower right-hand corner of the screen, check the network icon. If everything is connected, it should be an icon of a computer monitor with a cable to the right side.

    If there is no internet connection, it will be an icon of a globe with a slashed circle.

  2. Check the network cable at both the laptop end and the wall end.

  3. Try a different cable.

  4. Try a different network jack.

  5. Try rebooting.

  6. Find a network technician.

iPad

  1. Press the home button to return to the desktop.

  2. Scroll through the home screens until you find the "Settings" app and click on it.

  3. Tap the "Wi-Fi" item on the left-hand side.

    1. Make certain that you are connected to the expected network. There will be a blue checkmark to the left of the name.

    2. Try disconnecting and reconnecting. MU WiFi sometimes makes internal changes that require everyone to reconnect.

11.J.4.b. I can hear the studio, but they can’t hear me! (Audio Problems — Remote End)

The exact steps to troubleshoot this problem will depend on which mixer you are using, which computer you are using, and which method you are using to connect the two.

Tascam Mixcast

  1. Check that the microphones are turned up and unmuted.

  2. Check that the master L and R channels on the right side of the Mixcast screen have levels from your microphones. Mute everything else and check the levels from the microphones.

  3. Check the microphone pre-amps.

    1. Tap the hamburger menu button to bring up the menu.

    2. Tap the first button that has a set of four icons: a microphone, a smartphone, a USB symbol, and a bluetooth symbol. The "Inputs" page will appear.

    3. Tap the button for the microphone. The "Level" page for that microphone will appear.

    4. Use the level control to adjust the pre-amp.

iPad and Tascam Mixcast — Handsfree TRRS Cable

Unfortunately, the iPad version of the Linphone application does not have many user adjustable settings.

  1. In Linphone, make certain the <Microphone> icon in unmuted.

  2. Double-check that both ends of the handsfree TRRS cable are connected.

    1. One end should be plugged into the headphone jack on the end of iPad (bottom left-hand corner if the iPad is propped up in its stand).

    2. The other end should be connected to the "TRRS" jack on the back of the Mixcast. It has a smartphone icon above it and the label "(TRRS)" below it.

    3. The "Input Select" switch on the back of the Mixcast should be switched toward the Smartphone / TRRS jack.

  3. Try unplugging and replugging the handsfree TRRS cable from both ends.

  4. Try rebooting the mixer.

  5. Try rebooting the iPad.

iPad and Tascam Mixcast — Bluetooth

Unfortunately, the iPad version of the Linphone application does not have many user adjustable settings.

  1. In Linphone, make certain the <Microphone> icon in unmuted.

  2. Double-check that bluetooth is enabled and connected.

    1. Press the home button to return to the home screen.

    2. Scroll through the home screens until you find the "Settings" app and tap on it.

    3. Tap the "Bluetooth" item on the left-hand side.

    4. Make certain that bluetooth is on.

    5. Check the list of "My Devices" and make certain that "TASCAM Mixcast" (or "Mixcast 2") is "Connected".

  3. Try rebooting the mixer.

  4. Try rebooting the iPad.

Laptop and Tascam Mixcast — USB

  1. In Linphone, click the kebab menu button, then "Settings".

  2. "Microphone" should be "WASAPI: Microphone (Mixcast 4)".

  3. If the "Microphone (Mixcast 4)" option are missing, double-check the USB connection between the laptop and the Mixcast.

  4. Try unplugging and replugging the USB cable from both ends.

  5. Try rebooting the Mixcast.

  6. Try rebooting the laptop.

Laptop and Yamaha MG12XU USB Mixer

  1. Check that the microphones are turned up, unmuted, and in "ST" (Stereo).

  2. Check the microphone gain and compressor at the top of each channel.

  3. Check that the master "Stereo" channel is turned on and up.

  4. In Linphone, click the kebab menu button, then "Settings".

  5. "Microphone" should be "WASAPI: Line (MG-XU)".

  6. If the "Line (MG-XU)" option is missing, double-check the USB connection between the laptop and the Yamaha.

  7. Try unplugging and replugging the USB cable from both ends.

  8. Try turning the mixer off and back on again.

  9. Try rebooting the laptop.

11.J.4.c. The studio can hear me, but I can’t hear them! (Audio Problems — Remote End)

The exact steps to troubleshoot this problem will depend on which mixer you are using, which computer you are using, and which method you are using to connect the two.

iPad and Tascam Mixcast — Handsfree TRRS Cable

  1. Make certain that the volume on the iPad is turned up. The volume buttons on the iPad are on the top, toward the left-hand side if the iPad is propped up in its stand.

  2. Tap the headphones / speaker / bluetooth button on the bottom right-hand corner of the screen.

  3. Select "Headphones".

  4. Double-check that both ends of the handsfree TRRS cable are connected.

    1. One end should be plugged into the headphone jack on the end of iPad (bottom left-hand corner if the iPad is standing up in its case).

    2. The other end should be connected to the "(TRRS)" jack on the back of the Mixcast. It has a smartphone icon above it and the label "(TRRS)" below it.

    3. The "Input Select" switch on the back of the Mixcast should be switched toward the Smartphone / TRRS jack.

  5. Try unplugging and replugging the handsfree TRRS cable from both ends.

  6. Check the smartphone channel on the Mixcast. Make certain that it is turned up and umuted.

  7. Check the input level of the smartphone channel.

    1. Tap the hamburger menu button to bring up the menu.

    2. Tap the first button that has a set of four icons: a microphone, a smartphone, a USB symbol, and a bluetooth symbol. The "Inputs" page will appear.

    3. Tap the button for the smartphone. The "Level" page for the Smartphone input will appear.

    4. Use the level control to adjust the input level.

  8. Try rebooting the Mixcast.

  9. Try rebooting the iPad.

  10. Reconnect when troubleshooting is complete.

iPad and Tascam Mixcast — Bluetooth

  1. Make certain that the volume on the iPad is turned up. The volume buttons on the iPad are on the top, toward the left-hand side if the iPad is propped up in its stand.

  2. Tap the headphones / speaker / bluetooth button on the bottom right-hand corner of the screen.

  3. Select "Bluetooth (Tascam Mixcast)" (or Mixcast 2).

  4. Double-check that bluetooth is enabled and connected.

    1. Press the home button to return to the home screen.

    2. Scroll through the home screens until you find the "Settings" app and tap on it.

    3. Tap the "Bluetooth" item on the left-hand side.

    4. Make certain that bluetooth is on.

    5. Check the list of "My Devices" and make certain that "TASCAM Mixcast" (or "Mixcast 2") is "Connected".

  5. Check the bluetooth channel on the Mixcast. Make certain that it is turned up and umuted.

  6. Check the input level of the bluetooth channel.

    1. Tap the hamburger menu button to bring up the menu.

    2. Tap the first button that has a set of four icons: a microphone, a smartphone, a USB symbol, and a bluetooth symbol. The "Inputs" page will appear.

    3. Tap the button for the bluetooth. The "Level" page for the Bluetooth input will appear.

    4. Use the level control to adjust the input level.

  7. Try rebooting the Mixcast.

  8. Try rebooting the iPad.

  9. Reconnect when troubleshooting is complete.

Laptop and Tascam Mixcast — USB

  1. In Linphone, click the kebab menu button, then "Settings".

  2. "Speakers" should be "WASAPI: Speakers (Mixcast 4)".

  3. If the "Speakers (Mixcast 4)" option is missing, double-check the USB connection between the laptop and the Mixcast.

  4. Try unplugging and replugging the USB cable from both ends.

  5. Try rebooting the Mixcast.

  6. Try rebooting the laptop.

Laptop and Yamaha MG12XU USB Mixer

  1. Check that the "USB In" channel on the mixer is on, up, and in "1-2" only (not in "ST").

  2. Check that the "Line / USB" button just below the RCA jacks is set to "USB".

  3. In Linphone, click the kebab menu button, then "Settings".

  4. "Speaker" should be "WASAPI: Line (MG-XU)".

  5. If the "Line (MG-XU)" option is missing, double-check the USB connection between the laptop and the Yamaha.

  6. Try unplugging and replugging the USB cable from both ends.

  7. Try turning the Yamaha USB Mixer off and back on again.

  8. Try rebooting the laptop.
